ContractIQ

A production-grade multi-agent contract intelligence platform built on Google ADK, Gemini 3.1 Pro, and Vertex AI Agent Engine. Processes 100s of contracts in parallel, extracts structured data, scores risk, and routes to human review.

Stack Google ADK v1.33 · Gemini 3.1 Pro · Vertex AI · Python 3.11 Revised May 2026 MVP timeline 6 weeks

01

Problem & Solution Overview

Legal teams spend 60–80% of their time on manual contract review. A mid-sized M&A deal produces 500+ documents. Enterprise compliance teams review thousands of vendor agreements per year. Error rates under deadline pressure are high, and institutional knowledge about contract standards lives in individual lawyers' heads, not systems.

ContractIQ solves this by deploying a coordinated team of specialised AI agents — each with a focused role — orchestrated by Google ADK and powered by Gemini 3.1 Pro's 2M-token context window. The result: a batch of 100 contracts is processed in under 10 minutes, producing structured JSON, executive summaries, risk heatmaps, and Word redlines — all reviewable through a clean dashboard with human-in-the-loop approval before any output is finalised.

Key competitive advantage

Gemini's 2M token context window is the only model capable of loading an entire 300-page contract + your playbook + 50 precedent clauses into a single context. No chunking. No RAG retrieval loss. Full document reasoning.

What it does

  • Batch ingestion — upload PDFs, DOCX, or scanned documents; OCR handled automatically
  • Clause extraction — structured pull of 40+ clause types: indemnity, IP, payment, termination, limitation of liability, governing law, etc.
  • Playbook comparison — each clause scored against your firm's standard playbook; deviations flagged with severity
  • Risk scoring — contract-level and clause-level risk scores with natural-language explanation
  • Redline generation — suggested rewrites for non-standard clauses, in the style of your precedent language
  • Human-in-the-loop review — lawyer approves, overrides, or escalates before any output is locked
  • Structured output — JSON export for downstream CRM/CLM, Word redlines, PDF executive summary

EXTRACTOR_INSTRUCTION = """
You are a senior contract lawyer specialising in clause extraction.

You will be given:
1. A full contract document (via Gemini Files API file_uri)
2. The firm's standard playbook defining expected clause language
3. A list of precedent clauses from similar contracts

Your task: extract ALL of the following clause types from the contract.
For each clause, return:
- clause_type: one of the 40 standard types
- original_text: exact text from the contract
- page_ref: page number(s) where clause appears
- is_standard: true if matches playbook, false if deviates
- deviation_summary: brief note if is_standard is false

CLAUSE TYPES TO EXTRACT:
indemnity, limitation_of_liability, ip_ownership, ip_assignment,
payment_terms, payment_schedule, late_payment, termination_for_cause,
termination_for_convenience, termination_notice, governing_law,
dispute_resolution, arbitration, confidentiality, non_compete,
non_solicit, data_protection, security_requirements, audit_rights,
force_majeure, assignment, subcontracting, change_control,
warranties, representations, conditions_precedent, insurance,
liability_cap, exclusion_of_consequential_loss, most_favoured_nation,
benchmarking, step_in_rights, liquidated_damages, sla_terms,
service_credits, renewal_auto, renewal_notice, price_escalation,
entire_agreement, severability

Return ONLY valid JSON matching the ClauseBundle schema.
Do not add any explanation outside the JSON object.
"""

extractor_agent = Agent(
    name="extractor_agent",
    model="gemini-3.1-pro-preview",
    description="Extracts all contract clauses as structured JSON",
    instruction=EXTRACTOR_INSTRUCTION,
    tools=[
        FunctionTool(load_playbook),
        FunctionTool(load_precedents),
    ],
    output_key="clause_bundle",
    generate_content_config={
        "response_mime_type": "application/json",
        "response_schema": ClauseBundle.model_json_schema(),
    }
)

Risk scorer agent

agents/risk_scorer.pyfrom google.adk.agents import Agent
from google.adk.tools import FunctionTool
from tools.playbook_tools import get_risk_thresholds
from models.contract import RiskReport

RISK_INSTRUCTION = """
You are a contract risk analyst. You will receive:
1. A ClauseBundle JSON (extracted clauses from a contract)
2. Risk thresholds from the firm's playbook
3. The contract context (parties, value, type)

Score each clause 0-100 for risk (0=no risk, 100=critical):
- HIGH risk (score 70-100): Clause poses significant legal or commercial risk.
  Examples: uncapped indemnity, IP assigned to counterparty, no limitation of liability
- MEDIUM risk (score 40-69): Non-standard but negotiable.
  Examples: payment terms longer than 30 days, auto-renewal without notice
- LOW risk (score 0-39): Minor deviation or fully acceptable.

For each clause also provide:
- risk_category: legal | commercial | operational | regulatory
- explanation: 1-2 sentence plain English explanation of the risk
- recommended_action: ACCEPT | NEGOTIATE | ESCALATE | BLOCK

Also produce:
- contract_risk_score: overall 0-100 score (weighted average)
- critical_flags: list of clause_types with HIGH risk
- executive_summary: 3-sentence plain English summary for non-lawyers

Return ONLY valid JSON matching the RiskReport schema.
"""

risk_scorer_agent = Agent(
    name="risk_scorer_agent",
    model="gemini-3.1-pro-preview",
    description="Scores contract risk against firm playbook",
    instruction=RISK_INSTRUCTION,
    tools=[FunctionTool(get_risk_thresholds)],
    output_key="risk_report",
    generate_content_config={
        "response_mime_type": "application/json",
        "response_schema": RiskReport.model_json_schema(),
    }
)

HITL (human-in-the-loop) agent

agents/hitl.pyfrom google.adk.agents import Agent
from google.adk.tools import FunctionTool
from tools.notification_tools import send_review_notification
import asyncio

async def request_human_review(
    job_id: str,
    risk_report: dict,
    reviewer_email: str,
    sla_hours: int = 24
) -> dict:
    """
    Sends review notification and waits for human decision.
    Polls Firestore every 60s for reviewer response.
    Returns decision: {action: APPROVE|OVERRIDE|ESCALATE, notes: str}
    """
    await send_review_notification(
        job_id=job_id,
        review_url=f"https://contractiq.your-domain.com/review/{job_id}",
        risk_score=risk_report["contract_risk_score"],
        critical_flags=risk_report["critical_flags"],
        reviewer_email=reviewer_email,
    )

    # Poll for decision with timeout
    deadline = asyncio.get_event_loop().time() + (sla_hours * 3600)
    while asyncio.get_event_loop().time() < deadline:
        decision = await check_review_decision(job_id)
        if decision:
            return decision
        await asyncio.sleep(60)

    # SLA exceeded — auto-escalate
    return {"action": "ESCALATE", "notes": f"SLA exceeded: {sla_hours}h"}

hitl_agent = Agent(
    name="hitl_review_agent",
    model="gemini-3-flash",
    description="Pauses pipeline for human lawyer review",
    instruction="""
    Check the risk_report. If contract_risk_score > 50 or any critical_flags exist,
    invoke request_human_review and wait for the decision before proceeding.
    If score <= 50 and no critical flags, set review_decision to AUTO_APPROVED.
    Store the decision in output_key 'review_decision'.
    """,
    tools=[FunctionTool(request_human_review)],
    output_key="review_decision",
)

Pydantic data models

models/contract.pyfrom pydantic import BaseModel
from typing import Literal, Optional
from enum import Enum

class RiskLevel(str, Enum):
    HIGH = "HIGH"
    MEDIUM = "MEDIUM"
    LOW = "LOW"

class ExtractedClause(BaseModel):
    clause_type: str
    original_text: str
    page_ref: list[int]
    is_standard: bool
    deviation_summary: Optional[str] = None

class ClauseBundle(BaseModel):
    contract_id: str
    contract_type: str
    parties: list[str]
    effective_date: Optional[str] = None
    clauses: list[ExtractedClause]
    missing_clauses: list[str]  # Expected but not found

class ClauseRisk(BaseModel):
    clause_type: str
    risk_score: int          # 0-100
    risk_level: RiskLevel
    risk_category: Literal["legal", "commercial", "operational", "regulatory"]
    explanation: str
    recommended_action: Literal["ACCEPT", "NEGOTIATE", "ESCALATE", "BLOCK"]

class RiskReport(BaseModel):
    contract_id: str
    contract_risk_score: int
    clause_risks: list[ClauseRisk]
    critical_flags: list[str]
    executive_summary: str
    recommended_action: Literal["APPROVE", "NEGOTIATE", "REJECT"]

ADK runner entrypoint

main.pyimport asyncio
from google.adk.runners import Runner
from google.adk.sessions import InMemorySessionService
from google.adk.memory import VertexAiMemoryBankService
from google.genai import types
from agents.orchestrator import root_agent
from config import settings

async def run_contract_review(job: dict) -> dict:
    memory_service = VertexAiMemoryBankService(
        project=settings.GCP_PROJECT,
        location=settings.GCP_REGION,
    )
    session_service = InMemorySessionService()
    runner = Runner(
        agent=root_agent,
        app_name="contractiq",
        session_service=session_service,
        memory_service=memory_service,
    )

    session = await session_service.create_session(
        app_name="contractiq",
        user_id=job["user_id"],
        state={
            "job_id": job["job_id"],
            "document_uris": job["document_uris"],
            "playbook_id": job["playbook_id"],
            "reviewer_email": job["reviewer_email"],
        }
    )

    user_message = types.Content(
        role="user",
        parts=[types.Part(text=f"""
            Review the following contracts for job {job['job_id']}.
            Documents: {job['document_uris']}
            Playbook: {job['playbook_id']}
            Reviewer: {job['reviewer_email']}
            Execute the full pipeline: ingest, extract, score, redline, review, output.
        """)]
    )

    result = await runner.run_async(
        user_id=job["user_id"],
        session_id=session.id,
        new_message=user_message,
    )
    return result

State machine — job status transitions

QUEUED → INGESTING → EXTRACTING → SCORING → REDLINING
       → PENDING_REVIEW → [human action]
           → APPROVED   → FORMATTING → COMPLETE
           → OVERRIDDEN → FORMATTING → COMPLETE
           → ESCALATED  → MANUAL_REVIEW (exits automated pipeline)
           → [SLA timeout] → AUTO_ESCALATED

# Error states (any stage can transition to these)
→ FAILED_INGESTION     (document corrupt or unreadable)
→ FAILED_EXTRACTION    (model error — retry 3x then fail)
→ FAILED_SCORING       (model error — retry 3x then fail)

Cost & Scaling Model

Cost baseline assumption

A typical NDA is ~8 pages (~4,000 tokens). A complex commercial agreement is ~50 pages (~25,000 tokens). Gemini 3.1 Pro pricing (May 2026): $3.50/M input tokens, $10.50/M output tokens. Gemini 3 Flash: $0.075/M input, $0.30/M output.

Per-contract cost breakdown (average 20-page contract)

Ingestion agent (Gemini 3 Flash, ~1K tokens)~$0.001
Extractor agent (Gemini 3.1 Pro, ~12K in + 3K out)~$0.073
Risk scorer agent (Gemini 3.1 Pro, ~5K in + 2K out)~$0.038
